# 校名 / 校徽素材加工

由 `苏州科技大学-logo-1024px.png` 和 `name.jpg`（校名艺术字扫描图）加工而来，脚本 `process_logos.py` / `make_name.py` / `make_motto.py` 可重跑，产物与模板 `assets/` 目录中实际引用的文件一一对应。

| 文件 | 内容 | 用途 | 规格 |
|---|---|---|---|
| `sust_logo_blue.png` | 校徽 · 蓝色 #0066B3 | 封面 / 致谢页左上角（浅底） | 1024×1024，透明底 |
| `sust_logo_white.png` | 校徽 · 纯白 | 正文页眉右侧（深蓝带） | 1024×1024，透明底 |
| `sust_name_v2_blue.png` | 校名 · **中文为主体 + 英文缩小附下** · #0066B3 | 封面 / 致谢页校徽右侧 | 1674×513，透明底 |
| `sust_name_v2_white.png` | 同上 · 纯白 | 备用（当前未引用） | 1674×513 |
| `sust_name_cn_white.png` | 校名 · **纯中文** · 纯白 | 正文页眉右侧 | 1680×442，透明底 |
| `sust_motto_navy.png` | 校训水印"致远至恒 务学悟真"·**华文隶书**（已选定） | 章节页右下角水印（opacity 0.28） | 1200×613，透明底 |
| `sust_motto_navy_备选-华文行楷.png` | 同上 · 华文行楷 | 备选 | 1200×661 |
| `sust_motto_navy_备选-方正舒体.png` | 同上 · 方正舒体（毛体韵味） | 备选 | 1200×674 |
| `sust_motto_navy_备选-华文新魏.png` | 同上 · 华文新魏（碑刻感） | 备选 | 1200×699 |

## 注意

- **校名图分两版**：封面/致谢用「中文+英文」版（中文占图高 86%，英文放大到 0.8 倍以免在封面尺寸下不可读）；页眉高度只有 0.58cm，两行版英文会糊成一条线，故页眉单独用纯中文版。
- **校名与校徽等高**：tex 中封面 `\SUSTDrawBrand` 校徽/校名均 `height=1.08cm`，页眉 `\SUSTLogo`/`\SUSTHeaderBrand` 均为 `.58cm`；因页眉品牌块变宽，`\SUSTSectionNavigation` 宽度由 `.76\paperwidth` 收窄至 `.72\paperwidth`。
- **校名颜色 = 校徽主体蓝 #0066B3**（校徽上另有深一档 #004B88，如需更暗可改 `make_name.py` 里 `BLUE` 常量重跑）。
- **校训用系统艺术字体渲染**，仍非官方书法校训图，拿到官方图后同名替换即可。
